# 代码检查与 Bug 修复记录

本目录用于持续记录万楼进销存系统的代码审查、问题定位和修复结果，避免问题只留在聊天记录中。

## 检查范围

- 后端接口、权限与数据隔离
- 单据状态流转、库存增减与回滚
- 胶带分切及库存成本计算
- 前端交互、分页与导出
- 数据库迁移和真实业务数据保护
- 自动化回归检查及用户反馈

## 工作约定

1. 每次开始前先读仓库根目录的 `CLAUDE.md`，并查看 `git status`。
2. 发现问题时，在 `问题台账.md` 记录影响、复现条件和证据；不把猜测写成已确认缺陷。
3. 修改前确认业务口径；涉及数据库时使用可重复执行的迁移，不重建真实数据库。
4. 修复后更新问题状态和验证记录。项目要求的基础流程为 `node test/flow-test.js`；涉及具体模块时也执行相关回归脚本。
5. 所有由本助手完成的后续代码修改都在 `codex/review-and-bugfix` 分支进行；用户明确指定其他分支时按用户要求执行。
6. 用户在 `测试问题汇总.txt` 中记录的问题，修复后保留原始条目并标记状态。

## 文件说明

- `问题台账.md`：审查发现和 Bug 修复状态。
- `检查记录模板.md`：每轮检查的记录模板。
- `首轮检查记录.md`：本次建立目录时的首轮静态检查记录。
