# 万楼进销存系统

河南万楼商贸有限公司的进销存系统，用于替代现有的 SUM进销存（psi.sumdz.cn）。

## 目录结构

```
docs/        需求文档、老系统框架梳理、数据库设计
prototype/   可点击的 HTML 原型（当前阶段）
src/         正式代码
  backend/   服务端
  frontend/  前端
data/        导入模板（不含真实数据）
```

## 已确认的需求约束

1. **数据级权限**：销售只能看到自己负责的客户和单据；主管/管理员可看全部。
2. **扫码出库**：库管在仓库用手机扫码累积商品，生成出库单。老系统没有此功能。
3. **部署**：前期局域网部署，后期可迁至云服务器。
4. **数据迁移**：老系统历史数据完整迁移，不做裁剪。

## 原型预览

直接用浏览器打开 `prototype/index.html`。内置三个身份可切换（管理员刘国庆、销售朱俊青、库管夏安康），数据全部在内存中，刷新即重置。
