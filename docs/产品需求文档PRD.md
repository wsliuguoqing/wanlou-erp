## 一、产品概述

### 1.1 产品定位
万楼进销存系统是一套面向胶带等工业品贸易企业的库存管理系统，核心功能包括采购入库、销售出库、库存查询、客户管理、财务结算。

### 1.2 核心业务场景
- **销售出库**：销售员开出库单 → 选择客户和商品 → 系统自动扣减库存 → 生成销售记录
- **采购入库**：采购员开入库单 → 选择供应商和商品 → 增加库存 → 记录成本
- **胶带分切**：母卷按需分切成不同宽度的子卷，动态扣减可用宽度（不单独开单）
- **利润核算**：按出库单统计"已发货未开票"的订单毛利，供财务对账
- **权限控制**：销售、采购、财务、主管按角色分配不同操作权限

### 1.3 用户角色
| 角色 | 职责 | 权限范围 |
|------|------|----------|
| **销售员** | 开出库单、客户管理 | 只能看自己的出库单和客户，**不能查看成本和利润** |
| **采购员** | 开入库单、供应商管理 | 只能看自己的入库单和供应商，**不能查看销售价和利润** |
| **财务** | 开票登记、收款付款、查看利润报表 | 查看全部单据和利润报表，**可以看成本和销售价**，但不能修改库存 |
| **主管** | 审核单据、查看报表 | 查看全部数据，审核出入库单，**可以查看利润** |
| **超级管理员** | 系统配置、权限管理、删除数据 | **全部权限**，包括删除客户/供应商/物料，分配其他角色权限 |

**核心原则**：
- ✅ **成本和利润数据仅对财务、主管、超级管理员可见**
- ✅ **删除操作（客户/供应商/物料）仅超级管理员可执行**
- ✅ **所有角色权限由超级管理员分配和管理**

## 二、功能模块详细设计

### 2.0 用户管理与系统初始化 ⭐ **基础模块**

#### 2.0.1 系统初始化流程

**首次安装时的默认账号**：
- 账号：`admin`
- 密码：`admin123`
- 角色：超级管理员

**首次登录流程**：
1. 使用 `admin / admin123` 登录
2. 系统**强制要求修改密码**（不改密码无法进入系统）
3. 进入初始化引导页面：
   - 填写公司信息（公司名称、地址、联系方式）
   - 创建第一个仓库（如：主仓库）
   - 创建第一个销售员账号
   - 创建第一个采购员账号
4. 完成初始化，进入系统主界面

#### 2.0.2 用户/员工管理（仅超级管理员可见）

**功能位置**：左侧菜单 → 系统管理 → 用户管理

**员工列表**：
| 字段 | 说明 |
|------|------|
| 账号 | 登录用户名（唯一） |
| 姓名 | 员工真实姓名 |
| 角色 | 销售员/采购员/财务/主管/超级管理员 |
| 部门 | 所属部门（选填） |
| 手机号 | 联系方式 |
| 状态 | 启用/停用 |
| 最后登录时间 | 最近一次登录时间 |
| 创建时间 | 账号创建时间 |
| 操作 | 编辑/停用/启用/重置密码/删除 |

**筛选条件**：
- 角色筛选（全部/销售员/采购员/财务/主管/超管）
- 状态筛选（全部/启用/停用）
- 搜索（账号、姓名、手机号）

#### 2.0.3 新增员工

**必填字段**：
- 账号（3-20位字母数字，不能重复）
- 姓名
- **角色**（下拉选择：销售员/采购员/财务/主管/超级管理员）
- **初始密码**（至少6位，建议首次登录强制修改）

**选填字段**：
- 部门
- 手机号
- 邮箱
- 备注

**权限分配**：
- 选择角色后，**自动继承该角色的所有权限**
- 超级管理员可以看到权限明细（查看哪些菜单、哪些操作）

**保存后**：
- 账号立即生效，可以登录
- 建议打印或发送账号密码给员工

#### 2.0.4 编辑员工

**可修改**：
- 姓名
- 角色（**可以随时调整**，如：销售员 → 主管）
- 部门
- 手机号
- 邮箱
- 备注

**不可修改**：
- 账号（账号创建后不可改，避免历史数据混乱）

#### 2.0.5 重置密码

**操作**：
- 超级管理员点击"重置密码"
- 弹出对话框，输入新密码
- 确认后，该员工密码立即更新
- **建议**：重置为临时密码（如：`123456`），要求员工首次登录后修改

#### 2.0.6 停用/启用员工

**停用**：
- 员工离职或长期不用时，停用账号
- 停用后该账号**无法登录**
- 历史数据保留（出入库单仍显示该员工姓名）

**启用**：
- 恢复账号，可以重新登录

#### 2.0.7 删除员工

**规则**：
- **仅超级管理员可删除**
- 如果该员工有历史单据（出库单/入库单），**不允许删除**，只能停用
- 如果没有任何历史记录，可以删除

### 2.1 出库管理

#### 2.1.1 出库单列表
**功能描述**：显示所有出库单，支持筛选和搜索

**字段**（根据角色权限显示）：
- 出库单号（自动生成，格式：`hnwlo + 年月日时分秒 + 序号`）
- 出库日期
- 客户名称
- 销售员
- 销售合同号
- 销售总价（**所有角色可见**）
- ~~不含税成本总价~~（**仅财务/主管/超管可见，销售员不可见**）
- ~~毛利润~~（**仅财务/主管/超管可见**）
- ~~毛利率~~（**仅财务/主管/超管可见**）
- 是否开票（是/否）
- 单据状态（草稿/待审核/已审核/已完成）

**筛选条件**：
- 时间范围
- 客户名称（支持模糊搜索）
- 销售员
- 是否开票
- 单据状态

**权限**：
- **销售员**：只能看到自己的出库单，**不显示成本/毛利列**
- **财务/主管/超管**：可以看全部，**显示完整字段包括成本和利润**

#### 2.1.2 新增出库单
**流程**：
1. 选择客户（必填，从客户档案选择）
2. 填写销售合同号（选填）
3. 选择销售员（默认当前登录人）
4. 选择出库日期（默认今天）
5. 选择出库仓库（从仓库列表选择）
6. 添加出库明细：
   - 选择物料（支持搜索）
   - 显示当前库存数量
   - 填写出库数量（必填，不能超过库存）
   - **胶带分切特殊处理**：
     - 如果是母卷：填写"切取宽度"和"数量"，系统自动扣减母卷可用宽度
     - 如果是子卷：只能整卷出库
   - 填写销售单价（必填）
   - 自动计算：销售金额 = 数量 × 单价
   - **成本和毛利字段**：
     - **销售员**：不显示成本、毛利字段
     - **财务/主管/超管**：自动带出成本单价、成本金额、毛利
7. 底部显示合计：
   - **销售员**：只显示总金额
   - **财务/主管/超管**：显示总金额、总成本、总毛利、毛利率
8. **保存草稿 / 提交审核**（进入审批流程）

**校验规则**：
- 出库数量 > 0
- 出库数量 ≤ 可用库存
- 客户未超信用额度（超额提示警告，允许强制保存）
- 母卷分切：切取宽度 × 数量 ≤ 母卷剩余宽度

**审批流程**：
1. 销售员提交出库单 → 状态变为"**待审核**"
2. 主管/超管审核通过 → 状态变为"**已审核**" → 自动扣减库存
3. 主管/超管驳回 → 状态回到"**草稿**" → 销售员修改后重新提交
4. 已审核的单据可以标记"**已完成**"（发货完成）

**胶带分切示例**：
```
母卷：3M-1200，剩余宽度1180mm
操作：切取40mm × 30卷
扣减：40 × 30 = 1200mm（超出剩余宽度，提示错误）
修正：切取40mm × 29卷 = 1160mm（通过，母卷剩余20mm）
```

#### 2.1.3 出库单详情
**显示内容**（根据角色权限）：
- 单据头信息（客户、合同号、日期、销售员、仓库）
- 出库明细表格：
  - **所有角色**：商品、规格、数量、单价、销售金额
  - **仅财务/主管/超管**：成本单价、成本金额、毛利
- 底部合计：
  - **销售员**：销售额合计
  - **财务/主管/超管**：销售额、成本、毛利、毛利率
- 审批记录：制单人、提交时间、审核人、审核时间、审核意见
- 操作按钮：
  - **销售员（草稿状态）**：编辑、提交审核、删除草稿
  - **主管/超管（待审核状态）**：审核通过、驳回
  - **财务**：标记开票
  - **超管**：作废单据
  - **所有角色**：打印（打印单据不显示成本和利润）

**打印格式**（对外单据，不显示成本）：
- 抬头：公司名称、出库单号
- 客户信息：名称、联系人、电话
- 明细：序号、商品名称、规格、数量、单位、单价、金额
- 合计：大写金额
- 审批栏：制单人、审核人、日期
- **不打印成本和毛利**

4. **可选**：关联原出库单（如果能找到原单据）
   - 关联后自动带出原出库商品明细
   - 可以修改退货数量（不能超过原出库数量）
5. 添加退货明细：
   - 选择物料
   - 填写退货数量
   - 填写退货单价（一般等于原销售价）
   - 自动计算：退货金额 = 数量 × 单价
   - **胶带退货特殊规则**：
     - **子卷退货**：回到子卷库存，**不回母卷**
     - **母卷退货**：如果母卷未分切过，可以回到母卷库存
6. 底部显示合计：总退货金额
7. **保存草稿 / 提交审核**

**审批流程**：
1. 销售员提交退货单 → 状态变为"**待审核**"
2. 主管/超管审核通过 → 状态变为"**已审核**" → **自动增加库存**（退货入库）
3. 主管/超管驳回 → 状态回到"**草稿**"

**退款处理**：
- 审核通过后，财务在"收款管理"里记录一笔**负数收款**（相当于退款）
- 退货单标记为"已退款"

**库存处理**：
- 子卷退货 → 增加子卷库存（不回母卷）
- 母卷退货 → 如果母卷未分切，增加母卷库存；如果已分切，作为子卷入库
- 退货后成本：按移动加权平均重新计算

#### 2.2.3 退货单详情
**显示内容**：
- 退货单基本信息（单号、日期、客户、关联出库单）
- 退货明细表格（物料、数量、单价、金额）

- 单据状态

- **主管/超管**：可以审核盘点单（审核后才调整库存）
- **财务**：可以查看（包含金额）
- **销售员**：无权限

#### 2.4.5.2 新增盘点单
**流程**：
1. 选择盘点仓库
2. 选择盘点日期（默认今天）
3. **初始化盘点清单**：
   - 系统自动读取当前仓库的所有库存
   - 生成盘点明细（物料、账面数量、实盘数量=待填、盈亏数量=待计算）

   - 逐个物料填写"实盘数量"
   - 系统自动计算：**盈亏数量 = 实盘数量 - 账面数量**
   - 盈亏金额 = 盈亏数量 × 成本单价（仅财务/主管/超管可见）

6. **保存盘点单** → 状态变为"**已完成**"
7. **提交审核** → 状态变为"**待审核**"

**盘点明细字段**：
- 物料名称
- 规格
- 账面数量（系统自动带出）
- **实盘数量**（手工填写，必填）
- 盈亏数量 = 实盘 - 账面
- 成本单价（仅财务/主管/超管可见）
- 盈亏金额（仅财务/主管/超管可见）
- 批次号（如果有）
- 备注

**审批流程**：
1. 盘点人提交盘点单 → 状态变为"**待审核**"
2. 主管/超管审核通过 → 状态变为"**已审核**" → **自动调整库存**
   - 盘盈：增加库存
   - 盘亏：减少库存
3. 主管/超管驳回 → 状态回到"**盘点中**" → 盘点人修改后重新提交

**库存调整规则**：
- 盘盈：按当前成本单价入库
- 盘亏：按当前成本单价出库
- 调整后重新计算移动加权平均成本

- 可以查看**全部**单据和报表，**包括成本和利润**
- 不能新增/编辑出入库单（不能修改库存数据）

- 可以查看**全部**单据和报表，**包括成本和利润**
- 可以审核出入库单

### 3.3 审批流程（**已确认：需要**）

#### 出库单审批流程：
1. 销售员新增出库单 → 保存为"**草稿**"状态
2. 销售员**提交审核** → 状态变为"**待审核**"
3. 主管/超管**审核通过** → 状态变为"**已审核**" → **此时才扣减库存**
4. 主管/超管**驳回** → 状态回到"**草稿**"，附带驳回原因 → 销售员修改后重新提交
5. 已审核的单据可以标记"**已完成**"（发货完成）

**规则**：
- 草稿状态：销售员可编辑、删除
- 待审核状态：销售员不可编辑，只能撤回
- 已审核状态：任何人不可编辑，只有超管可作废
- **库存扣减时机**：审核通过时才扣减，避免库存提前锁定

#### 入库单审批流程：
1. 采购员新增入库单 → 保存为"**草稿**"状态
2. 采购员**提交审核** → 状态变为"**待审核**"
3. 主管/超管**审核通过** → 状态变为"**已入库**" → **此时才增加库存**
4. 主管/超管**驳回** → 状态回到"**草稿**"，附带驳回原因 → 采购员修改后重新提交

**规则**：
- 草稿状态：采购员可编辑、删除
- 待审核状态：采购员不可编辑，只能撤回
- 已入库状态：任何人不可编辑，只有超管可作废
- **库存增加时机**：审核通过时才增加

## 四、胶带分切业务专项设计

### 4.1 核心规则（已确认）

1. **分切不记单据**：出库时动态折算，不单独开拆装单
2. **母卷状态**：可多次分切，每次扣减`current_width`，直到剩余≤10mm自动标记为料头
3. **子卷状态**：已切下的子卷不可再分切，只能整卷出库
4. **料头**：剩余宽度<10mm时，标记为"料头"，不可用
5. **退货**：客户退回的子卷回到子卷库存，不回母卷
6. **混合开单**：一张出库单可以同时有母卷+不同规格子卷
7. **成本核算**：子卷成本 = (母卷单价 ÷ 可切数量) + 分切费

### 4.2 数据库设计

#### 4.2.1 物料表 (materials)
```sql
id              物料ID
name            物料名称（如"3M胶带1200"）
type            物料类型（母卷/子卷/成品/料头）
base_width      母卷初始宽度（母卷专用，如1200mm）
current_width   母卷当前宽度（母卷专用，动态更新）
spec            规格（子卷显示"40mm子卷"，成品显示"19mm×50m"）
cut_fee         分切费（子卷专用，元/卷）
threshold       料头阈值（默认10mm）
parent_id       父物料ID（子卷关联母卷，成品为NULL）
```

#### 4.2.2 出库单明细表 (outbound_items)
```sql
outbound_id     出库单ID
material_id     物料ID
quantity        数量
price           销售单价
amount          销售金额
cost_price      成本单价
cost_amount     成本金额
cut_width       分切宽度（母卷专用，如40mm）
cut_count       分切数量（母卷专用，如30卷）
note            备注
```

### 4.3 出库时的分切逻辑

#### 场景1：母卷分切出库
**用户操作**：
1. 选择母卷"3M-1200"，当前剩余宽度1180mm
2. 填写：切取宽度40mm，数量30卷
3. 填写：销售单价12元/卷
4. 系统计算：
   - 理论耗宽 = 40 × 30 = 1200mm
   - 检查：1200 > 1180 → 提示"剩余宽度不足"
   - 修正为29卷 → 理论耗宽1160mm → 通过
5. 保存后：
   - 母卷剩余宽度：1180 - 1160 = 20mm
   - 子卷库存：增加"40mm子卷"×29卷
   - 成本核算：
     - 母卷单价480元，可切1200÷40=30卷
     - 材料成本：480÷30 = 16元/卷
     - 分切费：0.5元/卷
     - 子卷成本：16 + 0.5 = 16.5元/卷
     - 销售毛利：(12 - 16.5) × 29 = -130.5元（**亏损**，价格太低）

#### 场景2：子卷整卷出库
**用户操作**：
1. 选择子卷"3M-1200 40mm子卷"，当前库存120卷
2. 填写：数量50卷
3. 填写：销售单价18元/卷
4. 系统计算：
   - 销售金额：18 × 50 = 900元
   - 成本：16.5 × 50 = 825元
   - 毛利：900 - 825 = 75元
5. 保存后：
   - 子卷库存：120 - 50 = 70卷

#### 场景3：母卷整支出库（不分切）
**用户操作**：
1. 选择母卷"3M-1200"，剩余宽度1180mm
2. 填写：数量1支（整支出库）
3. 切取宽度留空 → 系统识别为"整支出库"
4. 填写：销售单价420元/支
5. 保存后：
   - 母卷库存：-1支
   - 不影响子卷库存

### 4.4 料头处理
**触发条件**：
- 母卷剩余宽度 ≤ 10mm

**系统操作**：
1. 自动创建一条"料头"库存记录
2. 物料名称：原母卷名称
3. 规格：料头
4. 数量：1批
5. 标记为"不可用"
6. 母卷库存：-1支

**库存展示**：
```
3M胶带1200  料头  1批  不可用  成本10元
```

### 4.5 退货处理
**客户退回子卷**：
1. 客户退回"40mm子卷"×3卷
2. 系统处理：
   - 子卷库存：+3卷
   - **不**回母卷（无法再粘回去）
3. 子卷可再次出库，但不可分切

## 五、技术实现方案

### 5.1 技术栈选择

#### 方案A：前后端分离（推荐）
- **前端**：Vue 3 + Element Plus + Vite
- **后端**：Node.js + Express + MySQL
- **部署**：Docker 打包，本地或云服务器

**优点**：
- 界面美观，类似老系统风格
- 前后端分离，易于维护
- 支持多端（PC/手机/平板）
- 可随时扩展功能

**缺点**：
- 需要部署后端服务

#### 方案B：单体应用
- **技术**：Python Flask + SQLite + Jinja2 模板
- **部署**：打包成 exe，双击运行

**优点**：
- 部署简单，无需配置
- 适合单机使用

**缺点**：
- 界面不如方案A美观
- 不支持多人同时操作

### 5.2 数据库设计

**核心表**：
- users（用户表）
- roles（角色表）
- customers（客户表）
- suppliers（供应商表）
- materials（物料表）
- warehouses（仓库表）
- outbounds（出库单主表）
- outbound_items（出库单明细表）
- inbounds（入库单主表）
- inbound_items（入库单明细表）
- inventory（库存表）
- inventory_logs（库存流水表）
- payments（收款记录表）
- expenses（付款记录表）

详见：`数据库设计.md`

### 5.3 部署方式

**已确认**：先本地部署，后期再迁移到云服务器

#### 阶段一：本地部署（先期）
- 在你办公室的一台电脑上安装（作为服务器）
- 局域网内其他电脑通过 IP 访问（如：http://192.168.1.100:3000）
- 数据存在本地，安全可控
- 成本：0元（利用现有电脑）
- 访问范围：仅办公室局域网

**配置要求**：
- 操作系统：Windows 10/11 或 Ubuntu
- 内存：8GB 以上
- 硬盘：50GB 可用空间
- 需要固定内网 IP

#### 阶段二：云服务器部署（后期）
- 租用阿里云/腾讯云服务器
- 任何地方都能访问（外出办公、手机查看）
- 需要公网 IP 和域名
- 成本：约300-500元/年（2核4G配置）

## 六、仓库管理

### 6.1 仓库设置
**功能描述**：超级管理员可以创建和管理多个仓库

**仓库字段**：

- 新增出库单/入库单时，必须选择仓库
- 默认选择"主仓库"
- 可切换到其他仓库

### 6.3 库存按仓库隔离
- **库存查询**：可按仓库筛选
- **库存流水**：显示每笔流水的仓库
- **调拨单**（可选功能）：A仓库 → B仓库

## 八、与老系统的差异

| 功能点 | 老系统 | 新系统 |
|--------|--------|--------|
| 胶带分切 | 手动调整库存 | 自动扣减母卷宽度 |
| 权限控制 | 只有管理员权限 | **5种角色**（销售/采购/财务/主管/超管），精细权限，**销售员不能看成本和利润** |
| 审批流程 | 无 | **出入库单必须主管审核后才生效** |
| 成本核算 | 手动计算 | **移动加权平均法**，自动计算 |
| 批次管理 | 无 | 支持批次号、生产日期、保质期 |
| 利润核算 | 手动导出Excel计算 | 实时统计，自动计算，**仅高权限可见** |
| 移动端 | 不支持 | 响应式设计，手机可用 |
| 打印格式 | 固定模板 | 可自定义模板 |
| 数据导出 | 需要逐页复制 | 一键导出Excel |
| 仓库管理 | 单仓库 | **多仓库**，可自己创建 |
| 删除权限 | 管理员可删 | **仅超级管理员可删客户/供应商/物料** |
