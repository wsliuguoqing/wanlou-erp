# 需求确认清单

本文档是需求的唯一事实来源。每条需求标注状态：**已确认** / **待确认** / **已否决**。
讨论新功能前先查这里，避免反复。

---

## 一、已确认

### 1.1 权限（数据级）
- **已确认**：销售只能看到自己负责的客户和自己的单据。
- **已确认**：主管、管理员可以看到全部数据。
- **已确认**：成本价、毛利、毛利率仅最高权限可见；普通销售看不到。
- 待细化：客户「分配」给销售的规则（新客户谁负责？离职交接？）

### 1.2 单据与打印
- **已确认**：出库单是**内部单据**，应带销售价格。老系统打印模板不带价格属于缺陷。
- **已确认**：出库单详情要显示价格；**最高权限额外显示成本与利润**，普通权限看不到成本与利润。
- **已确认**：五套打印模板——入库单、入库退货单、出库单、出库退货单、送货单。
- **已确认**：送货单的**承运人在系统中填写**（如京东快递），打印时带出。
- **已确认**：退货单数量与金额用**负数**冲减原单，并记录原单编号。
- **已确认**：出库单页脚需要「发起人 + 审核人」双签名与时间。

### 1.3 扫码
- **已确认**：需要扫码出库（老系统没有）。
- **已确认**：部分商品包装箱自带厂家条码，没有的在后期自行打印条码标签，与新系统匹配。
- **已确认**：标签打印机与扫码枪已有现成的，无需采购。

### 1.4 部署与迁移
- **已确认**：前期局域网部署，后期可迁云。
- **已确认**：老系统历史数据完整迁移，不裁剪。

## 二、待确认（按优先级）

### 工作方式（已确认）
- **已确认**：不急于做成系统，**先把需求搞清楚**，一步步确认后再开发。原型只用于验证流程与字段，不是最终产品。

### A. 影响数据库表结构（最高优先级）

**A1. 条码怎么用？**
建议：物料主键仍是「物料编号」，厂家条码作为**附加查找键**存独立表（一个物料可对应多个条码，因为不同箱规条码不同）。自建标签的条码内容用物料编号，标签上同时打印品牌、品名、型号、规格，便于人眼核对。
待确认：同一物料会不会出现两个厂家条码？内部调拨或赠送的货要不要也贴标？

**A2. 数量允不允许小数？**
单位有「米」「卷」，是否有按米零售的情况？如果有，数量需支持 3 位小数；否则整数即可，能避免浮点误差。

**A4. 成本计价法用哪一种？**
老系统设置里有三种：移动加权平均、月末一次加权平均、先进先出。实际业务用的是哪一种？迁移时历史成本按哪种口径重算。

**A5. 负库存允不允许？**
老系统有「负结存」开关。开启了能先出后入，但库存会变负数。建议关闭，改为强校验。

### B. 影响流程与界面

**B1. 打印纸张规格？**
是 A4 激光打印，还是针式打印机多联单（241×140 等）？这直接决定打印模板的排版方式。

**B2. 审批由谁做？**
现在入库、出库都要审核。各由谁审核——库管主管？财务？还是老板一个人？金额超过多少要升级审批？

**A6. 出库价格默认带出哪个价？**
是带客户上次成交价、客户等级价，还是物料的最低销售价？三种都需要还是只用一种。

**A7. 合同要不要继续只做文本号？**
老系统采购/销售合同只是单据上的文本字段，没有独立的合同台账。是否需要记录合同金额、已执行量、未完成量、交期？还是保持现状只填编号。

**B4. 快递单号要不要记录并跟踪？**
送货单有承运人，是否还需要录入运单号，方便查件？

**B5. 送货单要不要电子签收？**
现在末尾是「请在此签名」。是打印后手签，还是希望手机上签收留档？

### C. 影响数据迁移

**C1. 迁移范围清单**
需要逐项确认：物料档案、客户、供应商、期初库存、全部入库单、全部出库单、两类退货单、应收余额、历史成本。是否还有**员工、角色权限、审批流程配置**需要迁？

**C2. 迁移后的老单号要不要保持原样？**
保持原样便于对账，但新系统的编号规则可能不同。建议：新单用新规则，老单原样保留并标记来源。

**C3. 历史单据里的「产品」列内容**
老系统「产品」列是「品牌 + 品名」拼接，部分与型号重复。迁移时能否按物料编号关联到新档案？关联不上的怎么处理（人工核对清单）？

### D. 运营相关

**D1. 同时在线几个人？**
决定服务器配置。7 个员工是否都开账号，是否多人同时开单。

**D2. 手机端要哪些功能？**
扫码出库已确认。销售要不要在手机上查库存、查自己客户的应收、看价格？

**D3. 数据备份策略**
局域网部署，备份放在哪台机器？每天几点自动备份？保留多少天？

**D4. 发票管理深度**
现在只记「发票状态 + 开票金额 + 发票号码」。要不要管进项发票与销项发票的匹配、税额汇总（用于报税）？
