# 胶带分切业务规则

## 场景描述

**典型案例**：采购一支 1200mm 宽胶带,分切后按不同宽度销售:
- 分切成 20mm 一卷,可卖 60 卷
- 分切成 40mm 一卷,可卖 30 卷
- 分切成 30mm 一卷,可卖 40 卷

进货单位可能是「支」,销售单位是「卷」,且同一物料可能对应多个销售规格。

---

## 对数据库设计的影响

### 1. 数量字段必须支持小数(DECIMAL(12,3))

原因:
- 分切后可能出现非整数销售量
- 中间工序可能有损耗(例如实际只能切 59.5 卷)
- 需要三位小数精度,避免累积误差

### 2. 需要「单位换算」功能

**方案 A: 物料主表增加换算比例字段**
```
物料表增加列:
- base_unit (基础单位, 如「支」)
- sale_unit (销售单位, 如「卷」)
- conversion_rate (换算比例, 如 60)
```
进一支 = 库存 +1 支 = 可售 60 卷

**方案 B: 独立换算表(支持一物多规格)**
```
物料单位换算表:
- material_id
- from_unit (如「支」)
- to_unit (如「卷-20mm」、「卷-40mm」)
- rate (60、30)
```
一个物料可以关联多个换算行,销售时选规格。

**推荐方案 B**,因为你们的胶带同一个进货批次会按需分切成不同宽度。

### 3. 库存显示需要双单位

出库单开单时,需要同时看到:
- 基础库存: 3 支
- 可用量(按 20mm 算): 180 卷
- 可用量(按 40mm 算): 90 卷

**UI 建议**: 物料选择器增加「规格」下拉,选定后自动换算可用量。

### 4. 成本分摊

进一支 1200mm 成本 480 元,分切后:
- 每卷 20mm 成本 = 480 ÷ 60 = 8.00 元
- 每卷 40mm 成本 = 480 ÷ 30 = 16.00 元

出库单保存时,**按换算比例自动折算为基础单位数量**扣减库存。例如:
- 销售 5 卷(20mm 规格) → 实际扣库存 5 ÷ 60 = 0.0833 支
- 成本按折算后的支数 × 单支成本

---

## 对迁移的影响

老系统的胶带类物料,可能存在:
1. 物料档案里基础单位与销售单位不一致
2. 历史出库单上的数量单位五花八门

**迁移策略**:
- 先梳理出所有「需要换算」的物料清单
- 为每个补录换算规则(或提供 Excel 批量导入)
- 历史单据保持原始记录,新系统显示时加换算提示

---

## 已确认规则

### 1. 分切不记单据,出库时动态折算
- 不做独立的拆装单
- 出库时填写:切取宽度、数量,系统按理论值自动扣减母卷可用宽度
- 例:1200mm母卷切3卷×40mm,扣减120mm(不记实际损耗)

### 2. 母卷与子卷的状态规则
- **母卷**(整支未动):可多次分切,每次扣减`current_width`,直到剩余宽度≤料头阈值(如10mm)
- **子卷**(已切下):不可再分切,只能整卷出库
- **料头**(剩余<10mm):标记为不可用,单独记在库存里

### 3. 退货处理
- 客户退回子卷(如3卷20mm),回到**子卷库存**,不回母卷
- 子卷库存可再次出库,但不能再分切

### 4. 混合开单
- 一张出库单**允许**同时有:母卷(整支) + 不同规格子卷
- 例:2支×1200mm母卷 + 30卷×40mm子卷
- 不同规格单价分别填写

### 5. 物料管理方式:同物料 + 规格字段
- 物料档案只记录母卷规格(如`3M-1200`)
- 库存表增加`spec`字段区分:`母卷` | `500mm` | `40mm` | `20mm` | `料头`
- 报表按规格分组显示

### 6. 分切损耗:按理论值扣减
- 系统按「宽度 × 数量」计算理论耗宽,不记录实际损耗
- 长期累积的误差需定期盘点调整

### 7. 子卷定价:材料成本 + 分切费
- 材料成本:母卷单价 ÷ 可切数量
  - 例:480元母卷切60卷20mm → 材料成本 480÷60 = 8元/卷
- 加工成本:每卷固定分切费(如0.5元/卷)
- **子卷成本 = 材料成本 + 分切费 = 8 + 0.5 = 8.5元/卷**
- 销售价手动填写(如12元),毛利 = 12 - 8.5 = 3.5元

### 8. 分切费配置
- 物料档案增加`cut_fee`字段,按规格记录分切费
- 可按宽度差异定价:
  - 20mm子卷:0.5元/卷
  - 500mm子卷:2元/卷(宽卷分切难度大)
