版本: v0.1  
日期: 2026-10-23  
基于需求确认清单 commit `49d0905`

---

## 一、设计原则

1. **数量精度**: 所有数量字段 `DECIMAL(12,3)`,支持胶带分切的小数量
2. **金额精度**: `DECIMAL(14,2)`,最大支持千万级含两位小数
3. **成本算法**: 移动加权平均,每次入库后立即重算
4. **库存管控**: 不允许负库存,出库时强校验
5. **审计追溯**: 所有主表包含`created_at`,`updated_at`,`created_by`,关键操作记日志
6. **附件存储**: 合同、收款/退款凭证存相对路径,文件存`attachments/`目录,按年月分文件夹

### 3. 库存核心表

#### `inventory` 库存主表

CREATE TABLE inventory (
  id            BIGINT PRIMARY KEY AUTO_INCREMENT,

## 三、关键业务逻辑

### 3.1 胶带分切流程

#### 出库母卷分切:
1. 选择物料(is_cuttable=1)、规格=master
2. 填写 cut_width(如40mm)、qty(如3卷)
3. 系统校验:
   - `inventory.current_width >= cut_width * qty`
   - `cut_width * qty + min_waste <= master_width` (确保不是料头)
4. 计算成本:
   - `material_cost = materials.current_cost * (cut_width * qty / master_width)`
   - `unit_cost = material_cost / qty + cut_fee`
5. 扣减库存:
   - `inventory(spec=master).qty -= (cut_width * qty) / master_width`
   - `inventory(spec=master).current_width -= cut_width * qty`
   - 如果 `current_width <= min_waste`,标记 spec=waste
6. 不生成子卷库存(子卷直接出库)

#### 退回子卷:
1. 创建 return_outbound,spec 记录子卷规格(如20mm)
2. 增加 `inventory(spec=20mm).qty`
3. **不回母卷**

### 3.2 成本计算(移动加权平均)

#### 入库时:
```
新成本 = (原库存qty * 原成本 + 入库qty * 入库单价) / (原库存qty + 入库qty)
```
更新 `materials.current_cost` 和 `inventory.cost`

#### 出库时:
- 普通物料:按 `inventory.cost` 扣减
- 母卷分切:按折算比例 `consumed_width / master_width` 计算耗用成本,再加 `cut_fee`

### 3.3 价格默认与确认

开出库单时:
1. 查询 `outbound_order_items` 最近一次该客户该物料的 `unit_price`
2. 如果有,带出并**标黄色背景**,`<input class="need-confirm" data-confirmed="false">`
3. 用户点击或修改后,`data-confirmed="true"`,颜色变正常
4. 提交时检查所有 `.need-confirm` 是否 confirmed,否则弹窗提示

## 四、附件存储规范

### 目录结构:
```
attachments/
  ├── contracts/2026/10/xxxxx.pdf
  ├── payments/2026/10/xxxxx.jpg
  └── refunds/2026/10/xxxxx.png
```

### 数据库存储:
只存相对路径,如 `contracts/2026/10/xxxxx.pdf`

### 文件命名:
`{类型}_{单据号}_{时间戳}.{扩展名}`  
例:`contract_CG202610230001_20261023143022.pdf`

## 五、索引与性能优化

1. 单据主表:`idx_date`,`idx_status` 用于列表分页
2. 明细表:外键自动创建索引,再加 `idx_material` 用于物料查询
3. 库存流水:`idx_material_time` 复合索引,支持按物料查流水
4. 客户/供应商:`idx_name` 支持模糊搜索

---

## 六、数据迁移注意事项

1. **物料档案**:老系统需补充 `is_cuttable`,`master_width`,`cut_fee`
2. **库存初始化**:
   - 普通物料 spec=normal
   - 母卷 spec=master,填写 current_width
   - 已切子卷 spec=具体宽度(如40mm)
3. **成本**:按移动加权法重算历史成本,或直接取老系统最后成本
4. **单据**:历史单据只导主要字段,明细保留原始数量单位
